Hajj Ops API · v1

Public read API · v11.8 schema · CORS enabled · cached at edge for 60s

The dashboard exposes a JSON API on top of the public data feed. Useful for connecting external tools, mobile apps, BI dashboards, MoH reports, or your own integrations. All endpoints respond with application/json and CORS-permissive headers.

Base URL

https://hajj.shuki.tech/api/v1/

Endpoints

GET /api/v1/health.json
Service status, version, build identifier. Use for monitoring.
GET /api/v1/personnel.json
Total roster breakdown — leadership, command, paramedics, GPs, and unit totals.
GET /api/v1/units.json
All operational units with assignments, sizes, types, and home stations.
GET /api/v1/stations.json
9 clinical stations + OCC. Includes unit composition and personnel counts per site.
GET /api/v1/movements.json
All 12 augmentation movements (PRE-B, B1A/B, B2A/B, GAP, C, D, E1, E2, MAINT) with from/to flows.
GET /api/v1/ambulances.json
25 ALS ambulances by class (Essential, Backup, Roving) and home station.
GET /api/v1/calendar.json
Hajj day calendar (1–15 DH) with phase, events, and Gregorian dates.
GET /data.json
Full data.json contents — all sections, suitable for ETL or backup.
GET /api/v1/pcr/proxy?url={GAS_URL}&endpoint={endpoint}
Server-side proxy for the Google Apps Script PCR endpoint. Useful for clients that need a non-Google domain to avoid CORS issues. Requires url to be a valid script.google.com URL.

Example

curl https://hajj.shuki.tech/api/v1/personnel

Connecting your own data

The dashboard can also pull live PCR (Patient Care Records) and Patient Census from your own Google Sheets via Google Apps Script. See the deployable GAS template and the in-app Settings → Google Apps Script endpoint.

Versioning & changes

This is the v1 API on the v11.8 data schema. Breaking changes will publish under /api/v2/. Current version returned in /api/v1/health.json.
